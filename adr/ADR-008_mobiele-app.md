# TITEL
008 mobiele app


# STATUS
Accepted


# CONTEXT 


# DECISION
een mobiele app zal dienen als bijkomende interface om met de hub te kunnen interageren.


# GEVOLGEN
## Voordelig
+ **[useability]** Een mobiele app maakt de UI toegankelijker dan een web app via de browser.

## Nadelig
- **[maintainability]** Een mobiele app vormt een extra systeem om te onderhouden.
